    KNOWN LIMITS

    A defensible demo says what it cannot prove.

    SC-08: a quotation about an old request can support an exact citation and still be misread as a present instruction. Independent verification establishes account and recipient, not current human intent. A customer-confirmation control would require a reviewed contract and could itself over-block real requests.

    SC-06: this evaluation stops before independent supervisor approval. Earlier resource-side tests are separate evidence, not one stitched end-to-end episode.

    Recovery: coherent rollback of all local state remains undetectable without an independent anchor. Protected-action release remains blocked. This static site cannot execute agents, approve material, restore databases, or submit API-108/API-109.
